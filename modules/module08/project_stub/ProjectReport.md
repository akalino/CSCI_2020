# Final Project Starter (CSCI 2020)

## Launch Binder
Use the course Binder link from Brightspace or the course GitHub page.

## What to edit
- `project.ipynb` is your main demo notebook.
- Put reusable code in `src/` (optional but encouraged).
- Put small example inputs in `data/`.
- Your program should write outputs to `output/`.

## How to run
1. Open `project.ipynb`
2. Kernel → Restart & Run All
3. Confirm the notebook runs without errors and outputs are produced.

## What to submit
Download your project folder as a ZIP and submit it to the Brightspace:
- `project.ipynb`
- `README.md`
- `data/` (small, non-sensitive)
- `output/` (sample outputs or generated by notebook)
- `src/` (if used)
